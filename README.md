# LingoScreenshotExtractor
Lingo app does not let you extract your notes from the app. It only exports plain glucose data - which is useless when you can not compare it against the food. This powershell script will take screenshot for you and keep it inside one folder - so that you can send it to your favorite AI agent and do analysis based on that. 

This was tested on s26 ultra. Your input tap cooridinates will vary depnding on the phone you are using. Best of luck
